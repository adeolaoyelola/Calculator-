# Simple Calculator

A beginner Python calculator that performs basic mathematical operations.

About

I created this project while learning Python as part of my Software Development T Level.

The calculator allows the user to enter two numbers and choose between addition, subtraction, multiplication and division.

Technologies Used

* Python

What I Learned

This project helped me practise:

* Variables
* User input
* Converting input into numbers using float()
* Mathematical operators
* if, elif and else statements
* Using different operations based on user input

How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open calculator.py in a Python editor such as VS Code.
4. Run the programme.
5. Enter two numbers and choose an operation.

Future Improvements
